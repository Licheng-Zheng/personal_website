Global Argument Mapper [STATUS: IN ACTIVE DEVELOPMENT]

Knowledge Graphs Web Scraping FAISS IndexIVFPQ

Context: Mapping nuanced, large-scale debates across the internet requires ingesting massive volumes of unstructured text and structuring it into a queryable semantic format.

Architecture: Constructing a robust automated web scraping pipeline that feeds into a dense Knowledge Graph. To handle the scale of semantic similarity search required for mapping arguments, the system utilizes Facebook's FAISS (specifically IndexIVFPQ) for highly compressed, inverted file system vector search.

Current Status: Actively developing the data ingestion and FAISS vector indexing pipeline to ensure sub-millisecond retrieval times on billions of scraped embeddings.

Simsoc: Dynamic State Sorting [STATUS: IN ACTIVE DEVELOPMENT]

PyTorch FLAME GPU Reinforcement Learning

Context: Simulating complex multi-agent systems via Reinforcement Learning on GPUs often leads to severe performance degradation due to warp divergence when agents enter different behavioral states.

Architecture: Engineering an environment that simulates complex agents entirely within GPU VRAM. To mitigate warp divergence, the architecture heavily employs dynamic GPU Radix Sorts to continually reorder agents by state memory contiguously, ensuring threads within a CUDA warp execute identical instruction paths.

Current Status: Implementing the core PyTorch to FLAME GPU data flow and validating the computational overhead of continuous sorting against the baseline divergence penalty.

Airfoil Optimizer

Python Matplotlib CFD Math

Objective: Automate the iterative generation and evaluation of airfoil geometries based on strict aerodynamic constraints.

Implementation: Built a programmatic solver that processes desired lift-to-drag ratios and structural constraints to output mathematical curve optimizations. The tool sidesteps complex graphical user interfaces in favor of pure, scriptable numerical evaluation and static plot generation.

Automated GoTo Telescope Mount [STATUS: IN ACTIVE DEVELOPMENT]

C/C++ STM32 / ESP32 Bare-Metal Firmware

Context: Precision astronomical tracking requires translating complex celestial coordinate mathematics directly into micro-stepped motor movements.

Architecture: Utilizing bare-metal C/C++ firmware targeting STM32 and ESP32 microcontrollers. The architecture bypasses heavy OS layers to achieve strict real-time execution limits, ensuring that the physical hardware actuation precisely mirrors the calculated sidereal tracking rates without latency jitter.

Current Status: Currently wiring the stepping drivers and calibrating the translation algorithms between the firmware math and the physical gear ratios.
