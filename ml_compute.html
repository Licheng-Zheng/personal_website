Compoxel: TreePM PyTorch Operator

C++ CUDA FLAME GPU 2 PyTorch C++ API

Situation: Large-scale N-Body gravity simulations conventionally run as separate processes from deep learning workflows, creating severe PCIe memory transfer bottlenecks when attempting to train models directly on simulation dynamics.

Task: Architect a massive-scale N-Body solver that lives entirely within the PyTorch ecosystem as a native, differentiable (where applicable) operator.

Action: Built the V1 architecture using FLAME GPU 2. Implemented complex mathematical voxel hashing and a hybrid TreePM (Tree Particle-Mesh) algorithm to manage gravitational force calculations. Bound the entire engine directly to PyTorch using the PyTorch C++ API.

Result: Successfully deployed a custom tensor operator that eliminates the PCIe bottleneck, allowing for high-performance, massive-scale gravity simulations directly alongside standard PyTorch tensor operations.

Hyperspectral VAE (UTAT Space Systems)

PyTorch VAEs Hyperspectral Data

Situation: Processing high-dimensional hyperspectral imaging data onboard aerospace systems is severely constrained by available compute and memory.

Task: Develop a heavily optimized architecture to compress and analyze hyperspectral data efficiently while retaining critical scientific features.

Action: Engineered a Variational Autoencoder (VAE) tailored specifically for hyperspectral data distributions, focusing on latent space regularization to ensure physical meaning is preserved in the compressed representation.

Result: Co-authored an industry publication as 3rd-author, accepted for presentation at the Small Sat Utah conference, validating the architecture's viability for real-world spaceflight applications.

PubMedBERT-CRF MLOps Deployment

FastAPI Docker HF Spaces PyTorch

Situation: Advanced biomedical NLP models utilizing custom PyTorch layers (like Conditional Random Fields for sequence tagging) are notoriously difficult to deploy using standard, out-of-the-box inference APIs.

Task: Architect a scalable, zero-cost MLOps pipeline to serve a custom PubMedBERT-CRF architecture for real-time inference.

Action: Stripped down the model dependencies and packaged the custom PyTorch architecture into an optimized Docker container exposing a high-throughput FastAPI endpoint.

Result: Successfully deployed the containerized system to Hugging Face Spaces, achieving robust, free, and scalable inference for complex biomedical named entity recognition (NER).

Agentic Researcher: RAG Pipeline and Personality Layers

FastAPI Groq API ChromaDB PyTorch RNNs RAG

Situation: Standard LLM interactions lack long-term statefulness and the ability to autonomously synthesise specific, dense knowledge bases without hallucination.

Task: Build an autonomous research agent capable of retrieving accurate technical data while maintaining a consistent, stateful "personality" across long-context interactions.

Action: Architected a Retrieval-Augmented Generation (RAG) pipeline utilizing ChromaDB for fast vector search and the Groq API for ultra-low latency LLM inference. Intersected this pipeline with custom PyTorch Recurrent Neural Networks (RNNs) specifically trained to act as dynamic personality and state-tracking layers.

Result: Deployed a high-speed FastAPI backend that successfully fuses static vector retrieval with dynamic, RNN-driven agentic state, enabling sustained and contextually accurate research workflows.
