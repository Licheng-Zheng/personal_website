Timmy and Tommy: Open-Book Medical RAG Pipeline

Status COMPLETED (V1)
Tech Stack PyTorch, ChromaDB, FastAPI, Groq

An exploration into Retrieval-Augmented Generation (RAG) vs. Fine-Tuning. By pairing an 8-billion parameter base model with a localized ChromaDB semantic search engine and custom recurrent neural networks (RNNs) for persona tracking, this pipeline approaches the USMLE benchmarking scores of Google's 540B parameter Med-PaLM at a fraction of the compute cost.

1. Pipeline Architecture

User queries are interpreted by multiple custom Recurrent Neural Networks (RNNs) before relevant claims are found in the vector database. The "Tommy" Cognitive RNN extracts the user's semantic intent and maps it to a 64-dimensional persona latent space. The "Timmy" Emotional RNN tracks state across interactions to synthesize a personality profile.

Architectural Choice

Why use custom RNNs instead of standard Transformers? An LLM API call costs 15-30 requests per minute against rate limits. A 100kb PyTorch RNN runs instantly in local memory for free, acting as a zero-latency prompt injection function.

Following persona calculation, the query traverses a localized ChromaDB instance. ChromaDB bypasses linear $O(N)$ searches by utilizing Hierarchical Navigable Small World (HNSW) graphs, reducing fetch times to $O(\log N)$ by relying on cosine similarity distances between embedded clinical claims:

$$ \text{Similarity}(A, B) = \cos(\theta) = \frac{A \cdot B}{\|A\| \|B\|} $$ Cosine Similarity for Semantic Retrieval

2. RAG vs. Fine-Tuning Trade-offs

The single biggest architectural debate in enterprise AI is whether to bake data into the model (Fine-Tuning) or attach a search engine to the model (RAG). Timmy uses a strict RAG approach to mitigate hallucinations and allow for zero-cost updatability.

Fine-Tuning (Med-PaLM)
Analogy: Closed-Book Test

Storage: Compressed statistically into billion-parameter neural weights.

Cost: Millions of dollars in TPU compute to update.

Reasoning: Deep. Understands systemic "grammar" of biology to theorize on novel cases.
RAG (Timmy/Ours)
Analogy: Open-Book Test

Storage: External deterministic Vector Database (ChromaDB).

Cost: Negligible. Drop a new text file into the DB instantly.

Reasoning: Shallow. Forced to echo hard text pulls; refuses to hallucinate novel scenarios.

3. USMLE (MedQA) Benchmarks

To prove the efficacy of the retrieval pipeline, the system was evaluated against the United States Medical Licensing Examination (USMLE) MedQA dataset under strictly Zero-Shot Chain of Thought (CoT) conditions.
